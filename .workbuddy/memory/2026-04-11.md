## 晚间：Bug 修复 - SQL 列不存在错误

### 问题
```
Unknown column 'gds.gb_dgs_dis_goods_id' in 'field list'
```

### 原因
迁移时在新项目中添加了不存在的数据库列引用：
- `NxGoodsMapper.xml` 第448行：`gds.gb_dgs_dis_goods_id`
- `GbDepartmentDisGoodsMapper.xml` 第154行：`gbDgsDisGoodsId`
- ResultMap 中有多余重复映射

### 修复
1. **NxGoodsMapper.xml** - SELECT 语句和 ResultMap 中移除：
   - 删除 `gds.gb_dgs_dis_goods_id`
   - 删除重复的 `gds.gb_dgs_gb_department_id`

2. **GbDepartmentDisGoodsMapper.xml** - ResultMap 中移除：
   - 删除 `<result property="gbDgsDisGoodsId" column="gb_dgs_dis_goods_id"/>`

### 教训
**迁移检查清单**：对比老项目 Mapper XML 和新项目，确保只引用数据库表中实际存在的列。
- 老项目搜索 `gb_dgs_dis_goods_id` 返回 0 结果
- 新项目错误添加了这个列的引用
