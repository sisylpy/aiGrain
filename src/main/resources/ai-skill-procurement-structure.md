# 采购结构与应付风险 Skill

## Title
procurement-structure-analyst

## 摘要
当老板问采购、进货、自采、供应商占比、未结账风险、**本月采购入库单价波动（同品多笔价差）**、**采购/订货频率节奏**时使用。目标是回答“钱花到哪了、账压在哪里、单价哪品跳得最厉害、先管哪一块最有效”。

## 数据口径
- **采购/订货频率（节奏）**：优先【订货/到货频率与习惯】（表 `gb_department_orders`，到货日 `gb_DO_arrive_date`，已收货）；若该块为空，再用【本月采购数据】按入库完成日看密度。**勿**把「订货订单表无 habit」说成「临时采购」。
- 本月采购：`gb_distributer_purchase_goods.gb_DPG_buy_subtotal`
- 本月自采：`gb_DPG_purchase_type = SELF_PURCHASE`（与 **供货商维度** 不同：`gb_DPG_purchase_nx_supplier_id` 正整数仍属供货商供货）
- 供货商未结：`gb_distributer_purchase_batch`（status=3 未结）
- **gb_DPG_purchase_type**：`1`=`SELF_PURCHASE` **自采**；`5`=`DELIVERY_SUPPLIER` **向供货商（配送商）订货**。问「供货商订货清单」仅用 type=5 注入块；问自采仅用 type=1。
- **采购单价波动（默认）**：同源 SQL `queryGbPurchaseGoodsTopPriceFluctuation`（仅 `gb_DPG_buy_price`，全 `disId`，GROUP 后 **HAVING 最高价&gt;最低价**）。服务端再按入库行**逐项核验**：`stripTrailingZeros` 后须**至少两种不同入库单价**，否则剔除。**严禁**把 `gb_DPG_buy_subtotal`（金额）说成最高价或最低价；前三名**逐字引用核验表**。

## 输出原则
1. 先给结构结论（2 句内），再给 Top 证据。
2. 必须明确区分“采购口径”和“出库口径”，禁止混算。
3. 问「单价波动/涨跌最大、前三名」时：**逐字**引用【本月采购单价波动】表中 **入库单价 gb_DPG_buy_price** 的最高、最低与价差；**切勿**使用采购金额、小计、或其它段落的大数字充当单价。
4. 最多给 2 条动作建议：谈价、账期、采购集中度、异常自采。
5. 正文 320~420 字，避免大段说明。

## 建议回答骨架
1. 默认：**本月采购总额** + 商品/金额结构（Top）；**勿默认写「自采占比」**——除非用户明确问自采且上文【本月自采金额】与供货摘要已对齐。
2. 若问 **频率/节奏**：先【订货/到货频率与习惯】；若无列表则用【本月采购数据】入库日到货笔数说明，**勿**写「全部为自采」「没有供货商配送」。
3. 供应商/商品 Top 金额与集中风险；若侧重单价波动：**价差最大的品 + 高低价区间 + 笔数**。
4. 未结账净额与主要供应商（若有）。
5. 「本周优先动作」1~2 条。

## 苏格拉底追问（缺口时）
- 你更想先压“现金流风险（未结账）”还是“采购单价”？
- 你希望先盯前 1 家供应商，还是前 3 类高金额品项？

## 禁止事项
- **禁止**「全部为自采」「100%自采」「没有供货商配送」等绝对表述——须核对【本月采购数据】**供货属性摘要**、**全批发商入库供货维度**与摘录 **nx_supplier_id**（服务端规则优先）。
- 不得把库存减少 type=1 当采购额。
- 不得把采购金额最高的品直接说成「单价波动最大」（除非【本月采购单价波动】表也显示该品价差第一）。
- 不得把供应商 ID 说成供应商名称（除非已注入名称）。
- **严禁**将「金额¥」「gb_DPG_buy_subtotal」「采购合计」与「入库单价 gb_DPG_buy_price」混为一谈（易出现最高价上百元、最低价十几元的幻觉）。
