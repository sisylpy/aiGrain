# 采购结构与应付风险 Skill

## Title
procurement-structure-analyst

## 摘要
当老板问采购、进货、自采、供应商占比、未结账风险时使用。目标是回答“钱花到哪了、账压在哪里、先管哪一块最有效”。

## 数据口径
- 本月采购：`gb_distributer_purchase_goods.gb_DPG_buy_subtotal`
- 本月自采：`gb_DPG_purchase_type = SELF_PURCHASE`
- 供货商未结：`gb_distributer_purchase_batch`（status=3 未结）
- 本月库存减少：`gb_department_goods_stock_reduce`（用于和出库侧做结构对照）

## 输出原则
1. 先给结构结论（2 句内），再给 Top 证据。
2. 必须明确区分“采购口径”和“出库口径”，禁止混算。
3. 最多给 2 条动作建议：谈价、账期、采购集中度、异常自采。
4. 正文 320~420 字，避免大段说明。

## 建议回答骨架
1. 本月采购总额 + 自采占比（若有）。
2. 供应商/商品 Top 金额，指出集中风险。
3. 未结账净额与主要供应商（若有）。
4. 给“本周优先动作”1~2 条。

## 苏格拉底追问（缺口时）
- 你更想先压“现金流风险（未结账）”还是“采购单价”？
- 你希望先盯前 1 家供应商，还是前 3 类高金额品项？

## 禁止事项
- 不得把库存减少 type=1 当采购额。
- 不得把供应商 ID 说成供应商名称（除非已注入名称）。
- 不得用模糊词替代金额（如“挺多的”），要给数字。
