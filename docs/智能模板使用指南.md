# 智能模板使用指南

## 概述

智能模板生成接口可以根据您提供的日期范围和部门ID，自动生成一个预填好日期和部门信息的Excel模板。您只需要在模板中填写数值字段即可，大大简化了数据录入流程。

## 接口信息

### 基本接口
- **接口地址**: `GET /ai/daily-revenue/download-smart-template`
- **请求方式**: GET
- **参数**: 查询参数（Query Parameters）

### 请求参数
| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| startDate | String | 是 | 开始日期，格式：yyyy-MM-dd | 2024-03-01 |
| endDate | String | 是 | 开始日期，格式：yyyy-MM-dd | 2024-03-31 |
| departmentId | Integer | 是 | 部门ID | 123 |

### 响应
- **文件类型**: Excel (.xlsx)
- **文件名格式**: `日营业额模板_{部门名称}_{开始日期}_{结束日期}.xlsx`
- **示例**: `日营业额模板_北京分公司_2024-03-01_2024-03-31.xlsx`

## 使用步骤

### 第1步：获取部门信息
在调用接口前，您需要知道：
1. **部门ID**: 要填写营业额的部门ID
2. **日期范围**: 需要录入数据的开始日期和结束日期

### 第2步：调用接口生成模板

#### 使用浏览器直接下载：
```
http://localhost:8090/ai/daily-revenue/download-smart-template?startDate=2024-03-01&endDate=2024-03-31&departmentId=123
```

#### 使用Postman：
1. 方法：GET
2. URL: `http://localhost:8090/ai/daily-revenue/download-smart-template`
3. Query Params:
   - startDate: 2024-03-01
   - endDate: 2024-03-31  
   - departmentId: 123

#### 使用curl命令：
```bash
curl -OJ "http://localhost:8090/ai/daily-revenue/download-smart-template?startDate=2024-03-01&endDate=2024-03-31&departmentId=123"
```

### 第3步：打开并填写模板

生成的Excel文件包含：

#### 1. 部门信息区（第1行）
```
| 部门ID: 123 | 部门名称: 北京分公司 | 日期范围: 2024-03-01 至 2024-03-31 | 总天数: 31 | ... |
```

#### 2. 表头行（第3行）
```
| 日期 | 堂食营业额 * | 堂食订单数 * | 堂食顾客数 * | 外卖营业额 * | 外卖订单数 * | 平台抽成 * | 星期几 | 节假日 | 备注 |
```

#### 3. 数据区（第4行开始）
已经预填好：
- **日期列**: 自动生成日期范围内的所有日期
- **星期几列**: 自动计算对应的星期几（0=周日，1=周一，...，6=周六）

需要您填写：
- **堂食营业额**: 堂食收入金额，支持小数，单位：元
- **堂食订单数**: 堂食订单数量，整数
- **堂食顾客数**: 堂食顾客人数，整数
- **外卖营业额**: 外卖收入金额，支持小数，单位：元
- **外卖订单数**: 外卖订单数量，整数
- **平台抽成**: 外卖平台抽成金额，支持小数，单位：元

可选填写：
- **节假日**: 如"国庆节"、"春节"等
- **备注**: 其他说明信息

### 第4步：上传填写好的模板

使用Excel上传接口：
```
POST /ai/daily-revenue/upload-excel
Content-Type: multipart/form-data

参数：
- file: [填写好的Excel文件]
- departmentId: 123
- distributerId: [分配者ID]
```

## 示例场景

### 场景1：为某个部门生成月度模板

**需求**: 为部门ID 456的"上海分店"生成2024年4月份的营业额模板

**调用接口**:
```
http://localhost:8090/ai/daily-revenue/download-smart-template?startDate=2024-04-01&endDate=2024-04-30&departmentId=456
```

**生成文件**: `日营业额模板_上海分店_2024-04-01_2024-04-30.xlsx`

**模板内容**:
- 包含30天的日期（4月1日-4月30日）
- 自动计算每个日期对应的星期几
- 部门信息已预填
- 数值字段留空，等待填写

### 场景2：为特定时间段生成模板

**需求**: 为部门ID 789的"广州分店"生成2024年五一假期（5月1日-5月5日）的模板

**调用接口**:
```
http://localhost:8090/ai/daily-revenue/download-smart-template?startDate=2024-05-01&endDate=2024-05-05&departmentId=789
```

**生成文件**: `日营业额模板_广州分店_2024-05-01_2024-05-05.xlsx`

### 场景3：批量生成多个部门的模板

**需求**: 为多个部门生成同一时间段的模板

**解决方案**:
1. 分别调用接口生成每个部门的模板
2. 或编写脚本批量生成

```python
import requests

# 部门列表
departments = [
    {"id": 101, "name": "北京店"},
    {"id": 102, "name": "上海店"},
    {"id": 103, "name": "广州店"}
]

# 时间范围
start_date = "2024-03-01"
end_date = "2024-03-31"

for dept in departments:
    url = f"http://localhost:8090/ai/daily-revenue/download-smart-template"
    params = {
        "startDate": start_date,
        "endDate": end_date,
        "departmentId": dept["id"]
    }
    response = requests.get(url, params=params)
    
    with open(f"日营业额模板_{dept['name']}_{start_date}_{end_date}.xlsx", "wb") as f:
        f.write(response.content)
    
    print(f"已生成部门 {dept['name']} 的模板")
```

## 最佳实践

### 1. 日期范围选择
- **月度模板**: 建议使用整月范围，如"2024-03-01"至"2024-03-31"
- **季度模板**: 可按季度生成，如"2024-01-01"至"2024-03-31"
- **特定时段**: 如节假日、促销活动期间

### 2. 数据填写建议
- **统一单位**: 金额统一使用"元"，支持两位小数
- **整数字段**: 订单数、顾客数填写整数
- **日期格式**: 使用模板中预填的日期格式
- **数据验证**: 填写后检查数据合理性

### 3. 批量处理技巧
- **分部门处理**: 按部门分别生成和填写模板
- **分时间段处理**: 按周、月、季度生成模板
- **团队协作**: 多人同时填写不同部门的数据
- **进度跟踪**: 记录已处理完成的部门和日期

### 4. 上传注意事项
- **核对部门ID**: 确保上传时使用的部门ID与模板一致
- **检查数据完整性**: 确保所有必填字段都已填写
- **验证数据格式**: 检查金额格式是否正确
- **分批上传**: 大量数据可分批次上传

## 常见问题

### Q1: 可以生成超过365天的模板吗？
**A**: 不可以。系统限制最大日期范围为365天，避免文件过大。如果需要更长时间范围，建议分多个时间段生成。

### Q2: 如果部门名称包含特殊字符怎么办？
**A**: 系统会自动处理特殊字符，将文件名中的特殊字符替换为下划线，确保文件名合法。

### Q3: 生成的模板可以在手机上填写吗？
**A**: 可以。生成的Excel文件兼容主流手机办公软件，如WPS Office、Microsoft Excel移动版等。

### Q4: 模板中的数据可以修改吗？
**A**: 可以。您可以修改任何字段，但建议保持日期和部门信息不变，以确保上传时能正确匹配。

### Q5: 如果填错了数据怎么办？
**A**: 有两种解决方案：
1. **直接修改**: 在Excel中修改错误数据后重新上传
2. **使用更新接口**: 填写错误的数据上传后，可以使用更新接口修正

### Q6: 支持生成其他格式的模板吗？
**A**: 目前只支持Excel (.xlsx) 格式，这是最常用且兼容性最好的格式。如果需要其他格式，请使用基础模板。
