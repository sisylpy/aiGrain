## 迁移铁律（必须遵守）

### ⚠️ 最重要规则

1. **文件名完全一致**：所有文件必须和老项目（nongxinle-master）**一模一样的名称**
2. **不自己写方法**：Mapper/Service/Controller 里的方法**只能从老项目复制**，禁止自己创建新方法
3. **工具类完整拷贝**：utils 目录下所有文件**原封不动**拷贝，不做任何修改

## 三、注意事项

### 3.1 返回类
- **必须使用** `com.nongxinle.utils.R`
- **不要使用** `Result` 或 `ResultCode`

### 3.2 异常处理
- 使用老项目的 `RRException`
- 全局异常处理器返回 `R` 类型

### 3.3 日期处理
- 使用老项目的 `DateUtils`
- 尽量使用 `LocalDateTime`，避免 `Date`

### 3.4 包名规范
- 工具类：`com.nongxinle.utils`
- 常量类：`com.nongxinle.constant`
- 实体类：`com.nongxinle.entity`
- Mapper：`com.nongxinle.mapper`
- Service：`com.nongxinle.service`
- Controller：`com.nongxinle.controller`
