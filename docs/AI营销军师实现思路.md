# AI 营销军师 - 多轮对话系统实现思路

## 一、核心目标

构建适合餐饮行业的 AI 营销助手，实现：
1. **多轮对话**：支持上下文理解的连续对话
2. **记忆系统**：自动提取、保存、检索用户关键信息
3. **360度画像**：设计优惠券前，先全面了解餐厅
4. **分类支持**：三种对话类型（普通聊天/促销/公众号）

---

## 二、360度餐厅画像（上下文构建）

在调用 DeepSeek 设计优惠券之前，必须先整合以下 **7 个维度** 的数据：

```
┌─────────────────────────────────────────────────────────────────────┐
│                      AI 营销军师 - 餐厅全景画像                        │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐                │
│  │  L1 知识库   │  │  L2 营销历史 │  │  L3 菜品数据 │                │
│  │  优惠券方法   │  │  历史活动效果│  │  价格/名字   │                │
│  │  (18种摘要)  │  │  18种详情   │  │  热销/滞销  │                │
│  └─────────────┘  └─────────────┘  └─────────────┘                │
│                                                                     │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐  ┌───────────┐│
│  │  L4 公众号   │  │  L5 画像    │  │  L6 记忆    │  │ L7 消息   ││
│  │  最近4期文章 │  │  成本/房租  │  │  老板偏好   │  │ 最近对话  ││
│  │  内容分析   │  │  人工/客流  │  │  踩坑教训   │  │ 历史记录  ││
│  └─────────────┘  └─────────────┘  └─────────────┘  └───────────┘│
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 7 个维度详解

| 维度 | 数据来源表 | 包含内容 |
|:---|:---|:---|
| **L1 知识库** | `ai_knowledge` | 18种优惠券方法摘要+详情 |
| **L2 营销历史** | `ai_activity` | 历史优惠券名称、内容、效果数据 |
| **L3 菜品数据** | `goods` / `gb_distributer_goods` | 菜品名、价格、销量、成本 |
| **L4 公众号** | `wx_article` | 最近4期文章标题、内容摘要 |
| **L5 餐厅画像** | `ai_restaurant_profile` | 采购成本、房租、人工、客流量 |
| **L6 经验记忆** | `ai_memory` | 老板偏好、踩坑教训、承诺 |
| **L7 对话历史** | `ai_message` | 最近聊天内容 |

## 三、两阶段知识库查询

### 阶段一：摘要推荐

```
用户: "母亲节想搞活动预算有限"

→ 查询 18 种优惠券摘要
→ DeepSeek 根据餐厅情况推荐 2-3 种最适合
→ 返回推荐列表及理由
```

### 阶段二：详细策划

```
用户确认: "用节日券 + 赠品券"

→ 获取两种券的详细内容
→ 整合 7 个维度的完整画像
→ DeepSeek 生成个性化活动方案
```

## 六、完整对话流程

```
用户: "母亲节想搞个活动"

┌──────────────────────────────────────────────┐
│  Step 1: 获取餐厅全景画像                      │
│  - 餐厅画像（成本/房租/人工）                    │
│  - 菜品数据（价格/销量）                        │
│  - 历史活动（以前做过什么、效果如何）             │
│  - 公众号内容（最近4期在推什么）                │
│  - 老板记忆（偏好/性格/教训）                   │
└──────────────────────────────────────────────┘
                     ↓
┌──────────────────────────────────────────────┐
│  Step 2: 知识库摘要匹配                        │
│  - 18种优惠券摘要 → DeepSeek 快速推荐          │
│  - 返回: 建议使用 节日限定券 + 赠品券           │
└──────────────────────────────────────────────┘
                     ↓
┌──────────────────────────────────────────────┐
│  Step 3: 详细内容 + 策划                       │
│  - 获取优惠券详细做法                          │
│  - 整合 Step 1 的完整画像                      │
│  - DeepSeek 生成活动方案                       │
└──────────────────────────────────────────────┘
                     ↓
返回: 完整的母亲节活动策划方案
      （包含优惠券设计、成本预算、预期效果）
```

## 八、总结：360度画像 = 餐厅全貌

| 信息维度 | 作用 | 数据来源 |
|:---|:---|:---|
| **成本画像** | 知道能花多少钱 | 房租+人工+采购 |
| **菜品数据** | 知道推什么菜/清什么库存 | 菜品表 |
| **历史活动** | 知道以前效果怎么样 | 活动表 |
| **公众号** | 知道最近宣传什么调性 | 文章表 |
| **老板记忆** | 知道老板性格偏好 | 记忆表 |
| **营销知识** | 知道有哪些方法可用 | 知识库 |

> **核心理念**：不是随便推荐优惠券，而是先"看懂"这个餐厅，再设计"专属"方案。
