## 二、命名规范

### 1. 模块命名
| 类型 | 命名规则 | 示例 |
|------|---------|------|
| 模块名 | GbXxx / NxXxx | GbDepartment, NxGoods |
| 表名 | gb_xxx / nx_xxx | gb_department, nx_goods |
| 实体类 | XxxEntity | GbDepartmentEntity |
| Controller | XxxController | GbDepartmentController |
| Service | XxxService | GbDepartmentService |
| Mapper | XxxMapper | GbDepartmentMapper |

### 2. 字段命名
- 数据库：`snake_case`（下划线）
- Java：`camelCase`（驼峰）
- MyBatis-Plus 自动映射：`map-underscore-to-camel-case: true`

## 三、开发流程

### 步骤 1: 创建实体类

```java
@Data
@EqualsAndHashCode(callSuper = false)
@TableName("表名")
public class XxxEntity implements Serializable {
    
    @TableId(type = IdType.AUTO)
    private Integer xxxId;
    
    // 数据库字段
    private String xxxName;
    private Integer xxxStatus;
    
    // 非数据库字段
    @TableField(exist = false)
    private List<SubEntity> subList;
}
```

### 步骤 2: 创建 Mapper

```java
@Mapper
public interface XxxMapper extends BaseMapper<XxxEntity> {
    
    // 自定义查询方法
    List<XxxEntity> queryList(Map<String, Object> map);
    
    Integer queryCount(Map<String, Object> map);
}
```

### 步骤 3: 创建 Mapper XML

```xml
<mapper namespace="com.nongxinle.mapper.XxxMapper">

    <resultMap id="BaseResultMap" type="com.nongxinle.entity.XxxEntity">
        <id property="xxxId" column="xxx_id"/>
        <result property="xxxName" column="xxx_name"/>
    </resultMap>

    <!-- 自定义查询 -->
    <select id="queryList" resultMap="BaseResultMap">
        SELECT * FROM xxx WHERE status = #{status}
    </select>

</mapper>
```

### 步骤 4: 创建 Service

```java
public interface XxxService extends IService<XxxEntity> {
    
    List<XxxEntity> queryList(Map<String, Object> map);
}
```

```java
@Service
public class XxxServiceImpl extends ServiceImpl<XxxMapper, XxxEntity> 
    implements XxxService {
    
    @Override
    public List<XxxEntity> queryList(Map<String, Object> map) {
        return baseMapper.queryList(map);
    }
}
```

### 步骤 5: 创建 Controller

```java
@RestController
@RequestMapping("模块名")
public class XxxController {

    @Autowired
    private XxxService xxxService;

    @RequestMapping(value = "/接口路径", method = RequestMethod.POST)
    public R 接口名(@RequestBody(required = false) Map<String, Object> params) {
        // 业务逻辑
        return R.ok().put("data", result);
    }
}
```

## 四、接口规范

### 1. 请求方式
| 场景 | 方法 |
|------|------|
| 查询列表 | GET / POST |
| 查询详情 | GET |
| 新增 | POST |
| 修改 | POST |
| 删除 | POST |

### 2. 返回格式

```java
// 成功
return R.ok();
// 或
return R.ok().put("data", data);

// 分页
Map<String, Object> pageMap = new HashMap<>();
pageMap.put("totalCount", total);
pageMap.put("pageSize", limit);
pageMap.put("totalPage", (total + limit - 1) / limit);
pageMap.put("currPage", page);
pageMap.put("list", list);
return R.ok().put("page", pageMap);

// 错误
return R.error("错误信息");
return R.error(500, "服务器错误");
```

### 3. 空值检查

```java
if (list == null || list.isEmpty()) {
    return R.ok().put("data", new ArrayList<>());
}
```

## 五、迁移检查清单

每次从老项目迁移代码时，必须检查：

### Controller
- [ ] 接口路径 `@RequestMapping` 与原项目一致
- [ ] 请求方法（GET/POST）与原项目一致
- [ ] 参数名称和类型与原项目一致
- [ ] 返回数据结构与原项目一致

### Mapper
- [ ] SQL 查询条件与原项目一致
- [ ] ResultMap 映射与原项目一致
- [ ] 关联查询（JOIN）与原项目一致

### Entity
- [ ] 数据库字段映射正确
- [ ] 非数据库字段标记 `@TableField(exist = false)`

## 六、常见问题

### 1. MyBatis 参数找不到
```java
// 错误：使用 @Param("map") 但 XML 中直接用 key 名
@Select("SELECT * FROM xxx WHERE status = #{status}")
List<Xxx> query(@Param("map") Map<String, Object> params); // 错

// 正确方式1：不使用 @Param
List<Xxx> query(Map<String, Object> params); // XML 中直接用 #{status}

// 正确方式2：使用 @Param
List<Xxx> query(@Param("map") Map<String, Object> map); 
// XML 中用 #{map.status}
```

### 2. JSON 返回 null 字段
使用 `fastjson2` 配置忽略 null 字段，在 `application.yml` 中：
```yaml
spring:
  http:
    converters:
      preferred-json-mapper: fastjson2
```

### 3. 日期格式化
在实体字段上添加注解：
```java
@JsonFormat(pattern = "yyyy-MM-dd HH:mm:ss", timezone = "GMT+8")
private LocalDateTime createTime;
```
