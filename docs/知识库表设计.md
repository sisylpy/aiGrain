# 餐饮专家知识库 - 数据库设计

## 一、知识库定位

> **"钱多多"知识库 = 餐饮行业专家经验的集合**
> 
> 不是简单的优惠券库，而是涵盖餐饮经营各方面的智慧结晶。

---

## 二、知识库分类（大类）

| 类别 | code | 说明 |
|:---|:---|:---|
| 优惠券营销 | coupon | 18种优惠券方法 + 效果案例 |
| 菜单设计 | menu | 菜单结构、定价策略、爆品打造 |
| 餐厅装修 | decorate | 装修风格、动线设计、灯光氛围 |
| 人员管理 | staff | 招聘、培训、绩效考核 |
| 成本控制 | cost | 采购、库存、浪费控制 |
| 获客引流 | traffic | 线上线下获客方法 |
| 客户运营 | customer | 复购、会员、私域运营 |
| 节日营销 | festival | 各类节日活动策划 |
| 供应链 | supply | 供应商选择、仓储物流 |
| 法律合规 | legal | 证照、食品安全、劳动法 |

## 三、知识库主表 `gb_ai_knowledge`

```sql
CREATE TABLE gb_ai_knowledge (
    -- 基础信息
    gb_ai_knowledge_id      BIGINT PRIMARY KEY AUTO_INCREMENT,
    gb_ai_knowledge_uuid    VARCHAR(64) UNIQUE COMMENT 'UUID唯一标识',
    
    -- 分类信息
    gb_ai_knowledge_type    INT DEFAULT 0 COMMENT '对话类型: 0=通用, 1=促销, 2=公众号',
    gb_ai_knowledge_category VARCHAR(50) COMMENT '知识大类: coupon/menu/decorate/staff...',
    
    -- 内容信息
    gb_ai_knowledge_title   VARCHAR(255) NOT NULL COMMENT '知识标题',
    gb_ai_knowledge_summary VARCHAR(500) COMMENT '摘要（AI生成，1-3句话）',
    gb_ai_knowledge_content  TEXT NOT NULL COMMENT '详细内容（支持富文本/Markdown）',
    
    -- 来源信息
    gb_ai_knowledge_source_url VARCHAR(500) COMMENT '原文来源URL',
    
    -- 标签体系（多标签，用逗号分隔存储）
    gb_ai_knowledge_tags    VARCHAR(500) COMMENT '标签列表: 母亲节,满减,节日营销,低成本',
    
    -- 专家信息
    gb_ai_knowledge_author  VARCHAR(100) COMMENT '专家/作者名称',
    gb_ai_knowledge_origin   VARCHAR(200) COMMENT '来源: 钱多多/刘一刀/王装修...',
    
    -- 效果数据
    gb_ai_knowledge_effect_rating   INT DEFAULT 0 COMMENT '效果评分 1-5',
    gb_ai_knowledge_effect_cases     INT DEFAULT 0 COMMENT '应用案例数',
    gb_ai_knowledge_effect_note      VARCHAR(500) COMMENT '效果说明',
    
    -- 适用条件
    gb_ai_knowledge_suitable_restaurant VARCHAR(500) COMMENT '适用餐厅类型',
    gb_ai_knowledge_suitable_budget    VARCHAR(100) COMMENT '适用预算范围',
    gb_ai_knowledge_suitable_season    VARCHAR(100) COMMENT '适用季节',
    
    -- 统计
    gb_ai_knowledge_view_count   INT DEFAULT 0 COMMENT '查看次数',
    gb_ai_knowledge_use_count    INT DEFAULT 0 COMMENT '被推荐/使用次数',
    
    -- 状态
    gb_ai_knowledge_status       INT DEFAULT 1 COMMENT '状态: 0=草稿, 1=启用, 2=下架',
    
    -- 时间
    gb_ai_knowledge_publish_time DATETIME COMMENT '发布时间',
    gb_ai_knowledge_create_time  DATETIME DEFAULT CURRENT_TIMESTAMP,
    gb_ai_knowledge_update_time  DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    -- 索引
    INDEX idx_category (gb_ai_knowledge_category),
    INDEX idx_type (gb_ai_knowledge_type),
    INDEX idx_tags (gb_ai_knowledge_tags),
    INDEX idx_status (gb_ai_knowledge_status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='AI知识库主表';
```

## 五、知识库应用关联表 `gb_ai_knowledge_usage`

记录知识库被使用的情况，用于分析效果。

```sql
CREATE TABLE gb_ai_knowledge_usage (
    gb_ai_knowledge_usage_id       BIGINT PRIMARY KEY AUTO_INCREMENT,
    gb_ai_knowledge_id              BIGINT COMMENT '知识ID',
    gb_ai_knowledge_usage_department_id BIGINT COMMENT '使用餐厅ID',
    gb_ai_knowledge_usage_conversation_id BIGINT COMMENT '对话ID',
    gb_ai_knowledge_usage_result    VARCHAR(50) COMMENT '结果: 推荐/采纳/拒绝',
    gb_ai_knowledge_usage_effect    VARCHAR(50) COMMENT '效果反馈: 好/中/差',
    gb_ai_knowledge_usage_feedback  TEXT COMMENT '用户反馈详情',
    gb_ai_knowledge_usage_create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    
    FOREIGN KEY (gb_ai_knowledge_id) REFERENCES gb_ai_knowledge(gb_ai_knowledge_id)
);
```

## 七、多标签实现方案

### 方案一：逗号分隔（简单，推荐）

```sql
-- 存储
gb_ai_knowledge_tags = '母亲节,节日营销,低成本,情感营销'

-- 查询（使用 FIND_IN_SET）
SELECT * FROM gb_ai_knowledge 
WHERE FIND_IN_SET('母亲节', gb_ai_knowledge_tags) > 0;

-- 查询多个标签（AND 关系）
SELECT * FROM gb_ai_knowledge 
WHERE FIND_IN_SET('节日营销', gb_ai_knowledge_tags) 
  AND FIND_IN_SET('低成本', gb_ai_knowledge_tags);
```

### 方案二：JSON 数组（灵活）

```sql
-- 存储
gb_ai_knowledge_tags = '["母亲节", "节日营销", "低成本"]'

-- 查询
SELECT * FROM gb_ai_knowledge 
WHERE JSON_CONTAINS(gb_ai_knowledge_tags, '"母亲节"');

-- 模糊匹配
SELECT * FROM gb_ai_knowledge 
WHERE JSON_SEARCH(gb_ai_knowledge_tags, 'one', '%营销%') IS NOT NULL;
```

### 推荐：方案一（逗号分隔）

- 简单，易维护
- 支持索引
- 前端处理方便（split 即可）

## 八、知识库查询接口设计

### 8.1 获取所有类别
```
GET /api/ai/knowledge/categories
```

### 8.2 按类别+标签查询
```
GET /api/ai/knowledge/list?category=coupon&tags=母亲节,低成本&type=1
```

### 8.3 获取摘要列表（阶段一用）
```
GET /api/ai/knowledge/summary?category=coupon&type=1
返回：id, title, summary, tags（不含详细内容）
```

### 8.4 获取详细内容（阶段二用）
```
GET /api/ai/knowledge/detail/{id}
返回：完整知识内容 + 效果数据
```

### 8.5 记录使用反馈
```
POST /api/ai/knowledge/usage
{
  "knowledgeId": 1,
  "departmentId": 1,
  "conversationId": 1,
  "result": "采纳",
  "effect": "好"
}
```
